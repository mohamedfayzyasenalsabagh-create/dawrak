تجربة مجانية 7 أيام بكل الميزات. الدفع عبر شام كاش برفع صورة الإيصال، وصاحب النظام بيقبله فيتفعّل الاشتراك. إذا خلص الاشتراك بيتوقف إنشاء الطلبات.

## التنبيه عند الزبون

صوت + اهتزاز + إشعار والصفحة مفتوحة، والشاشة بتضل شغالة طول الانتظار. إذا سكّر الزبون المتصفح كلياً ما بيوصله الإشعار (هاد بدو خادم Firebase على خطة Blaze، ممكن نضيفه لاحقاً).
